# Snatching times in the chain-snatching videos

`tempi_scippo.json` is written by `python -m sicurezza.strumenti annota-scippi` (manual annotation, D15):
one row per video, `eventi` = list of `[start, end]` in seconds; `nessuno_scippo: true` = video to exclude.
The videos come from the Kaggle dataset `aniketsahu09/chain-snatching-cctv-dataset` (not included in the repo).
